# Correções de fidelidade — CharmanderGames
Referência: mockup Pokémon de 1536 × 864 fornecido pelo usuário.

## Implementado
- [x] Cabeçalho desktop de 72 px, banner de 315 px e margens de 23 px.
- [x] Busca global no cabeçalho, preservando as seis rotas.
- [x] Painel de ROMs com 355 px e estados reais.
- [x] Coluna do emulador de 420 px no desktop de referência.
- [x] Seis cards na página Pokémon, três em larguras intermediárias e dois no mobile.
- [x] Recortes de arte sem badges embutidos, badges únicos em HTML.
- [x] Títulos sobre a arte, degradê inferior e botões abaixo.
- [x] Filtros alinhados ao título no desktop, nomes completos das plataformas.
- [x] Console com tela, moldura e controles decorativos; prévia identificada e link funcional para o emulador.
- [x] Tipografia, espaçamentos, raios, sombras e faixa de benefícios ajustados.
- [x] Busca, filtros, favoritos, rotas e configuração de ROMs verificados por testes de lógica.

A ferramenta de navegador requerida pelo fluxo Sites não está disponível. As caixas implementadas indicam mudanças no código, não aprovação pixel perfect. As artes disponíveis são recortes do mockup; o enquadramento das capas exige revisão visual. A referência mobile do kit é uma prancha de componentes, não uma página Pokémon completa.
